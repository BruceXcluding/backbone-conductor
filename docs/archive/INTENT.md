# 初始意图

让多个 Coding Agent 在写代码之前共享目标与约束，在提交代码时检查结构化冲突，并让每一次意图、决策与仲裁变更能够通过 Git 追溯。

首版成功条件：不需要模型密钥即可从全新 Git 仓库完成「创建意图 → 接受 → 分派 → 开始 → 提交真实 Git 制品 → 检查 → 人工审查与 Git 合并 → 记录完成」，且可通过 CLI、HTTP 和 MCP 访问同一持久状态。

约束：Python 3.12+；Git 是权威存储；使用真实 MCP SDK；DSH 集成通过实际发布的 Python SDK；确定性检查不能冒充语义验证；不得把未合入目标分支的代码记录为已完成。
